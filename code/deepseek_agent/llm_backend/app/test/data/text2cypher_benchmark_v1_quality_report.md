## 指标可计算性

生成集共40题，每题占2.5个百分点，因此：

- 65% = 26/40；
- 85% = 34/40；
- 90% = 36/40。

这可以直接核验简历中的三个百分比，不需要对小数进行四舍五入。

## 使用边界

- 本数据集只能作为 `test_only` 保留集，禁止写入 Few-shot 向量索引。
- 参考答案依赖当前 Neo4j 数据快照；如果重新导入数据，需要重新运行质量校验。
- 数据库已增加 `ecommerce-v2` 规范标签与字段，原标签/字段仍保留以兼容本v1参考答案；后续生成链路必须使用规范子标签隔离两个数据域。
- 本次只校验了数据集质量，没有运行真实外部 LLM，也没有产生或认可65%、85%、90%的模型测试结果。
- Neo4j 对故意使用未知标签、关系和属性的验证样本会输出警告，这是预期的负例行为。
