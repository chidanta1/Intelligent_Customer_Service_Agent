## 常见问题解答

### 如何连接WiFi？
智能音箱连接WiFi的步骤如下：
1. 下载对应品牌的APP并注册登录
2. 将音箱通电，等待语音提示进入配网模式
3. 在APP中选择添加设备，按照提示输入WiFi密码
4. 等待配网成功的提示音

注意：音箱只支持2.4G WiFi，不支持5G WiFi。如果连接失败，请检查WiFi密码是否正确，或者尝试重启路由器和音箱。

### 智能门锁电池没电了怎么办？
智能门锁电量不足时会有语音提示和APP推送提醒，请及时更换电池。如果电池完全耗尽无法开锁，可以采取以下方法：
1. 使用应急充电宝通过门锁底部的Type-C接口临时供电开锁
2. 使用机械钥匙开锁
3. 联系开锁师傅处理

建议定期检查电池电量，当提示电量低于20%时就及时更换电池，避免突然没电。

### 如何申请退换货？
我们支持7天无理由退换货。退换货条件：商品未使用、包装完整、配件齐全、不影响二次销售。

申请流程：
1. 联系客服说明退换货原因
2. 客服审核通过后提供退货地址
3. 将商品完好寄回（建议保价）
4. 我们收到货后3个工作日内完成检查
5. 退款原路返回或发出换货商品

注意：人为损坏、私自拆封的商品不支持退换货。运费规则：非质量问题退货运费由买家承担，质量问题由我们承担。

### 智能设备支持哪些语音助手？
我们的智能设备支持主流的语音助手，包括：
- 小爱同学（小米）
- 天猫精灵（阿里）
- 小度（百度）
- Siri（苹果HomeKit）
- Google Assistant

不同品牌的产品支持的语音助手可能有所不同，购买前请确认产品详情页的兼容性说明。配置方法：在对应语音助手的APP中添加智能家居设备，按照提示完成授权和绑定即可。

## 使用技巧和建议

### 智能门铃使用技巧
1. 定期清理镜头，保持画面清晰
2. 根据实际情况调整侦测灵敏度，减少误报
3. 定期检查电量，及时充电
4. 建议购买云存储服务，保存重要视频
5. 合理设置侦测区域，避免误触发

### 智能音箱使用技巧
1. 放置在开阔位置，避免遮挡，提高识别率
2. 定期清理音箱表面灰尘
3. 避免阳光直射和潮湿环境
4. 合理设置音量，避免长时间大音量使用
5. 定期更新固件，获取新功能

### 智能门锁使用技巧
1. 定期检查电池电量，及时更换
2. 保持指纹传感器清洁，提高识别率
3. 录入指纹时建议多录几次，提高准确性
4. 定期清理锁孔，保持机械部分正常运作
5. 妥善保管机械钥匙，以备不时之需
